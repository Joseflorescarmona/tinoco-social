# Tinoco social

Images for the Instagram posts of [Tinoco](https://tinocokids.com), calm free games for kids.

`./ig-post.sh posts/<name>.jpg captions/<name>.txt` publishes one post (token stays on the Mac, never in this repo).


**Since 28 Nov 2026:** `ig-post.sh` no longer works, because the Graph API token is gone and won't be replaced. Post and schedule in Meta Business Suite (TinocoKids portfolio, @tinocokids.app); handle DMs and comments on instagram.com. Media files still live here (`reels/`, `stories/`, `posts/`, `captions/`).
